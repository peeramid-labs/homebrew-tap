# peeramid-labs homebrew tap

Public Homebrew tap for `slop` — a blazing-fast AI-slop firewall.

```bash
brew install peeramid-labs/tap/slop
# or grab latest HEAD:
brew install peeramid-labs/tap/slop --HEAD
```

See [slop-cli](https://github.com/peeramid-labs/slop-cli) for source
and the [skill bundle](https://github.com/peeramid-labs/slop-cli/blob/main/skills/slop.md)
for Claude integration.
